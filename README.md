# 보글사다리3 삼치기 Hedge V3.3 Final Meta

V3.1과 V3.2를 내부에서 동시에 계산하고, 두 결과가 같으면 그대로 합의값을 사용하며 서로 다르면 과거의 **충돌 회차만 따로** 미래누설 없이 순차학습해 최종 제외값을 고르는 독립 앱입니다.

## 핵심
- V3.1: 4개 조합 상대점수 경쟁으로 최저 1개 제외
- V3.2: 약/연속 구간에서 5엔진 재투표 및 검증우세 구조요청
- V3.3 Final Meta:
  - V3.1 = V3.2 → 같은 제외값 채택
  - V3.1 ≠ V3.2 → 충돌전용 메타성적 비교
  - 전체 충돌성적 + 현재상황 충돌성적 + 최근 충돌성적 + 기존 동일상황 정책성적을 표본보호 후 결합
  - 표본이 적으면 V3.2를 기본값으로 유지하고, 충분한 검증우위가 있을 때만 V3.1로 전환
- 같은 값 / 서로 다른 값 성공률을 별도 집계
- 충돌 시 V3.1, V3.2, V3.3 최종 성공률을 각각 표시
- V1 / V2 / V3.1 / V3.2 / V3.3 같은 구간 순차검증 비교
- 백그라운드 3분 자동추첨·채점·다음 분석 유지
- V1/V2/V3.1/V3.2 백업에서 과거 결과와 기본 배팅설정 가져오기 가능

## 표본보호
- 충돌 전체 표본이 8회 미만이고 현재상황 충돌표본이 6회 미만이면 메타결과를 과신하지 않습니다.
- 현재상황 충돌성적은 8회부터 반영을 시작해 20회까지 단계적으로 영향이 커집니다.
- 최근 충돌 최대 30회를 별도 추적합니다.
- 2/2, 3/3 같은 작은 표본 100%만으로 최종판정을 뒤집지 않습니다.

균등·독립 무작위라면 4개 중 3개 선택의 기준 성공률은 75%입니다. 앱의 점수와 등급은 실제 당첨확률을 보장하지 않으며, V3.3의 개선 여부는 수십 회가 아니라 충분한 순차검증 표본에서 V3.1/V3.2와 비교해야 합니다.
